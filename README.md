# WanderStay 🏡

WanderStay is an **Airbnb-inspired full-stack web application** that I built as my major project while learning and working with backend and full-stack web development.

The project allows users to explore property listings, create their own listings, manage them, and add reviews.

---

## About

I built WanderStay to understand how a real-world web application works from the backend to the database.

The project currently includes **user authentication, listing management, reviews, protected routes, sessions, and flash messages**.

---

## Features

* 🏡 View all property listings
* 🔍 View individual listing details
* ➕ Create new listings
* ✏️ Edit listings
* 🗑️ Delete listings
* 👤 User Signup & Login
* 🔐 Authentication & protected routes
* 🚪 User Logout
* ⭐ Add and delete reviews
* 💬 Success and error flash messages
* 📦 MongoDB database
* 📱 Responsive UI

## Getting Started

Clone the repository:

```bash
git clone https://github.com/vikas-suryawanshi/wanderStay.git
```

Go to the project folder:

```bash
cd wanderStay
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```
